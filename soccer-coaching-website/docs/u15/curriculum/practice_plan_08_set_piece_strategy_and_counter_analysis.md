# Practice Plan: Set Piece Strategy and Counter Analysis

## Objective:
To equip U15 players with advanced strategies for attacking and defending set pieces, and to introduce the concept of analyzing opponent tendencies from set plays.

## Key Concepts:
*   **Advanced Set Piece Routines:** Complex attacking plays for corners and free kicks.
*   **Defensive Set Piece Organization:** Sophisticated marking schemes and positional play.
*   **Opponent Set Piece Analysis:** Identifying opponent strengths and weaknesses from set pieces.
*   **Countering Set Pieces:** Strategies to transition effectively after defending a set piece.
*   **Communication and Leadership:** Clear calls and organization during set pieces.

## Session Structure:

**1. Warm-up (15 mins):**
*   **"Set Piece Delivery Accuracy" Challenge:
    *   **Setup:** Players practice delivering balls into specific zones of the penalty area (e.g., near post, penalty spot, far post) from various set piece positions.
    *   **Focus:** Precision, technique, and variety in delivery.
*   **"Run Pattern Recognition" Warm-up:
    *   **Setup:** Players practice common attacking runs for set pieces (e.g., "run across," "run away," "dummy run").
    *   **Focus:** Timing, movement off the ball, understanding run types.

**2. Skill Development (25 mins):
*   **Attacking Set Piece Routines (Corners & Free Kicks):
    *   **Setup:** Players practice specific, multi-player attacking routines for corners and free kicks.
    *   **Drill:** Focus on player roles (e.g., screeners, decoy runners, attackers in the box), timing of runs, and execution of the final action (header, volley, shot).
    *   **Focus:** Execution of complex set piece plays.
*   **Defensive Set Piece Organization:
    *   **Setup:** Players practice defensive organization against various set pieces (corners, direct free kicks).
    *   **Drill:** Focus on zonal responsibilities, man-marking assignments, "cutting out" dangerous passes, and effective clearances.
    *   **Focus:** Coordinated defense, clear communication, reducing opponent's chances.

**3. Tactical Application (30 mins):
*   **"Set Piece Analysis & Execution" Game:
    *   **Setup:** Present clips of opponent set pieces (or simulate them). Players analyze the opponent's strengths/weaknesses.
    *   **Drill:** Based on the analysis, players then practice executing their attacking or defensive strategies to counter or exploit the opponent's tendencies.
    *   **Focus:** Tactical analysis, application of strategies.
*   **"Transition from Set Piece" Drill:
    *   **Setup:** Simulate a defending scenario from a corner or free kick.
    *   **Drill:** After the ball is cleared or defended, players must transition immediately into an attacking move, focusing on speed and organization.
    *   **Focus:** Transitioning from defense to attack after set pieces.

**4. Cool-down (10 mins):**
*   Light jogging and static stretching.
*   Player reflection: "What is one thing you learned about analyzing opponent set pieces? How can better communication improve our defense on corners?"

**Coach’s Troubleshooting:**
*   **Inaccurate set piece delivery:** Dedicate specific time to practicing delivery. Encourage players to develop proficiency with both feet.
*   **Lack of defensive organization:** Assign clear roles (zonal, man-marking) and ensure players understand their responsibilities. Use diagrams to illustrate positioning.
*   **Players not understanding "opponent tendencies":** Use video analysis. Ask players to identify patterns in opponent set pieces during observation.

**Age-Appropriate Language:**
*   Use terms like "set pieces," "corners," "free kicks," "analysis," "opponent tendencies," "strategy," "execution," "transition," "routines," "zonal marking," "man marking," "communication."
*   Emphasize the importance of set pieces as scoring opportunities and defensive challenges.
